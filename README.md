# 🧮 Smart Calculator App

A simple and interactive **Calculator Web Application** built using **Python and Streamlit**.

The application performs basic and advanced mathematical operations with a clean and user-friendly interface.

## Live Demo

-  [Open Smart Calculator](https://calculator-app-jrcpnakzvhuq5xgyxf94yp.streamlit.app/)

##  Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📊 Percentage Calculation
- 🔢 Power Calculation
- √ Square Root
- ⚠️ Division-by-zero error handling
- 🎨 Simple and interactive Streamlit UI

## 🛠️ Technologies Used

- Python
- Streamlit
- Math
